# Описание транзакций

| Транзакция                    | Описание                                                                      | Тип            | Компенсация                   |
|-------------------------------|-------------------------------------------------------------------------------|----------------|-------------------------------|
| `CREATE_PAYMENT`              | Создать запись платежа и запустить оркестрацию.                               | повторяемая    | —                             |
| `HOLD_CLIENT_FUNDS`           | Заблокировать сумму на счёте клиента в банке.                                 | компенсируемая | `RELEASE_CLIENT_FUNDS`        |
| `FRAUD_CHECK`                 | Проверка транзакции (ALLOW / DENY / REVIEW).                                  | повторяемая    | —                             |
| `SUBMIT_MANUAL_REVIEW`        | Отправить задачу на ручную проверку в antifraud, ожидать решения до 20 минут. | повторяемая    | —                             |
| `APPLY_AUTO_APPROVAL_TIMEOUT` | Авто-разрешение по таймеру, если ответа по REVIEW нет.                        | повторяемая    | —                             |
| `CAPTURE_CLIENT_FUNDS`        | Финальное списание средств с заблокированной суммы.                           | компенсируемая | `REFUND_CLIENT_FUNDS`         |
| `TRANSFER_TO_CONTRAGENT`      | Перевод средств контрагенту.                                                  | компенсируемая | `REVERSE_CONTRAGENT_TRANSFER` |
| `MAKE_ACCOUNTING_ENTRY`       | Бухгалтерская запись по операции.                                             | компенсируемая | `REVERSE_ACCOUNTING_ENTRY`    |
| `NOTIFY_SUCCESS`              | Уведомление клиента об успешной оплате.                                       | повторяемая    | —                             |
| `NOTIFY_DECLINE`              | Уведомление клиента об отклонении/возврате.                                   | повторяемая    | —                             |
| `NOTIFY_SECURITY`             | Уведомление службы безопасности при подозрении на мошенничество.              | повторяемая    | —                             |
| `RELEASE_CLIENT_FUNDS `       | Снять холд (когда платеж отклонён до capture).                                | необратимая    | —                             |
| `REFUND_CLIENT_FUNDS`         | Возврат средств клиенту (компенсация после capture/ошибки payout).            | необратимая    | —                             |
| `REVERSE_CONTRAGENT_TRANSFER` | Обратная проводка/откат выплаты контрагенту                                   | необратимая    | —                             |
| `REVERSE_ACCOUNTING_ENTRY`    | Обратная бухгалтерская запись.                                                | необратимая    | —                             |
| `CANCEL_PAYMENT`              | Пометить платёж как отменённый/неуспешный, завершить сагу.                    | повторяемая    | —                             |
| `CANCEL_MANUAL_REVIEW`        | Закрыть задачу ручной проверки, если саге больше не требуется.                | повторяемая    | —                             |
